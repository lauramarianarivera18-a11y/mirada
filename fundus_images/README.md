# Datasets

Los datasets no se versionan en Git por su tamaño (~4 GB) y por sus licencias.
Descárgalos desde sus fuentes oficiales y colócalos en estas carpetas:

| Carpeta | Dataset | Fuente |
|---|---|---|
| `dataset_drive/DRIVE/` | DRIVE | https://drive.grand-challenge.org/ |
| `dataset_drive_av/AV_groundTruth/` | DRIVE AV (anotaciones arteria/vena) | https://doi.org/10.1167/iovs.12-10449 |
| `dataset_rite/` (`train/`, `validation/`, `test/`) | RITE | https://medicine.uiowa.edu/eye/rite-dataset |
| `dataset_idrid/` | IDRiD | https://ieee-dataport.org/open-access/indian-diabetic-retinopathy-image-dataset-idrid |
| `dataset_smdg/` | SMDG (Standardized Multi-Channel Dataset for Glaucoma) | https://www.kaggle.com/datasets/deathtrooper/multichannel-glaucoma-benchmark-dataset |
